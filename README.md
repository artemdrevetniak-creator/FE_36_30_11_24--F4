# Web Development Course

Навчальний репозиторій для практичних занять з веброзробки.

## 📚 Про курс

У цьому репозиторії зберігаються матеріали та практичні приклади, які використовуються під час занять.

Кожне заняття знаходиться в окремій **Git-гілці (branch)**.

```text
main
│
├── lesson-13-promise
├── lesson-14-promise-methods
├── lesson-15-rest-api
├── lesson-16-ajax
└── ...
```

Гілка `main` містить базову інформацію про курс і не прив'язана до конкретного заняття.

---

## 🌿 Гілки

Для кожного заняття використовується окрема гілка.

| Гілка                       | Тема             |
| --------------------------- | ---------------- |
| `lesson-13-promise`         | Проміси          |
| `lesson-14-promise-methods` | Методи промісів  |
| `lesson-15-rest-api`        | REST API         |
| `lesson-16-ajax`            | AJAX             |
| `...`                       | Наступні заняття |

> Список гілок поступово доповнюється в процесі проходження курсу.

## 🚀 Як почати роботу

### 1. Клонувати репозиторій

```bash
git clone https://github.com/artemdrevetniak-creator/FE_36_30_11_24--F4.git
```

Перейти до папки проєкту:

```bash
cd FE_36_30_11_24--F4
```

### 2. Вибрати потрібне заняття

Наприклад, для роботи з AJAX:

```bash
git checkout lesson-16-ajax
```

Або можна одразу клонувати конкретну гілку:

```bash
git clone -b lesson-16-ajax https://github.com/artemdrevetniak-creator/FE_36_30_11_24--F4.git
```

### 3. Встановити залежності

Якщо заняття використовує Node.js та npm:

```bash
npm install
```

### 4. Запустити проєкт

```bash
npm start
```

Команда запуску може відрізнятися залежно від конкретного заняття.

## 🔀 Робота з Git

Основний принцип роботи з репозиторієм:

```text
main
  ↓
lesson-01
  ↓
lesson-02
  ↓
lesson-03
  ↓
...
```

Нова гілка для заняття створюється на основі попереднього стану проєкту, якщо нова тема продовжує попередню.

Наприклад:

```bash
git checkout lesson-03-http
git checkout -b lesson-04-rest-api
```

Після завершення роботи:

```bash
git add .
git commit -m "Add REST API lesson"
git push -u origin lesson-04-rest-api
```
